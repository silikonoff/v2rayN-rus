## Возможности

| | Возможность | Для чего это нужно |
|:---:|---|---|
| 🗂️ | **Профили и подписки** | Храните несколько подключений, импортируйте ссылки и обновляйте списки серверов. |
| 🔀 | **Системный прокси** | Направляйте через прокси приложения, которые используют сетевые настройки системы. |
| 🌐 | **TUN** | Используйте виртуальный сетевой интерфейс для приложений, которые не работают с системным прокси. Возможности зависят от ОС, прав и настроек. |
| 🧭 | **Маршрутизация и DNS** | Выбирайте направление трафика и настраивайте разрешение имён с учётом возможностей ядра. |
| 🧩 | **Разные ядра** | Управляйте совместимыми сетевыми ядрами, включая Xray и sing-box. |
| 💾 | **Резервные копии** | Сохраняйте и восстанавливайте настройки и профили приложения. |

### Приложение и ядро — в чём разница?

**v2rayN** — это интерфейс для управления профилями и настройками. **Сетевое ядро** выполняет сами подключения. Для работы нужны совместимые профиль, ядро и сервер. Версии приложения и ядра обновляются отдельно: новая функция ядра не обязательно сразу доступна в интерфейсе.

## Протоколы

В таблице перечислены типы профилей и обработчики конфигураций, найденные в исходном коде. Это не гарантия совместимости всех сочетаний транспорта, версии ядра и настроек сервера.

| Профиль | Назначение | Обработчики в коде | Что учесть |
|---|---|---|---|
| **VLESS** | Подключение к совместимому серверу | Xray, sing-box | Транспорт и TLS/REALITY должны совпадать с сервером. |
| **VMess** | Подключение к совместимому серверу | Xray, sing-box | Проверьте параметры транспорта и безопасности. |
| **Shadowsocks** | Подключение через Shadowsocks | Xray, sing-box | Метод шифрования и пароль должны совпадать с сервером. |
| **Trojan** | Подключение к серверу Trojan | Xray, sing-box | Проверьте пароль, TLS и имя сервера. |
| **SOCKS / HTTP** | Использование существующего прокси-сервера | Xray, sing-box | Укажите адрес, порт и при необходимости учётные данные. |
| **Hysteria2** | Подключение к серверу Hysteria2 | Xray, sing-box | Нужны совместимые версии и доступность UDP. |
| **TUIC** | Подключение к серверу TUIC | sing-box | Требуются совместимый сервер и доступность UDP. |
| **WireGuard** | Подключение с параметрами WireGuard | Xray, sing-box | Проверьте ключи, адреса и версию ядра. |
| **AnyTLS / Naive** | Дополнительные типы прокси-профилей | sing-box | Доступность отдельных параметров зависит от версии ядра. |
| **MASQUE** | Подключение с параметрами MASQUE | Xray, sing-box | Проверьте поддержку и совместимость параметров с сервером. |
| **Custom** | Подключение с пользовательской конфигурацией | Зависит от конфигурации | Формат должен соответствовать выбранному ядру; используйте доверенный источник. |

Подробнее: [протоколы и ядра в руководстве](docs/ru/guide.md#протоколы-и-ядра).

## Быстрый старт

1. **Скачайте** подходящий файл из [официального релиза v2rayN](https://github.com/2dust/v2rayN/releases/latest) и распакуйте в отдельный каталог с правом записи.
2. **Добавьте профиль.** Скопируйте ссылку поставщика и выберите **Серверы → Импорт ссылок общего доступа из буфера обмена**. Для подписки откройте **Группа подписки → Настройки групп подписки**.
3. **Активируйте профиль.** Выделите сервер и выберите **Сделать активным**. Для подключения необходимо совместимое ядро.
4. **Включите системный прокси** через **Системный прокси → Установить системный прокси** и проверьте доступ к нужному ресурсу.
5. **Отключитесь:** выберите **Очистить системный прокси** и убедитесь, что обычный доступ восстановлен.

Для настройки TUN, DNS и правил маршрутизации воспользуйтесь [подробным руководством](docs/ru/guide.md).

## Обновления

> [!IMPORTANT]
> Файлы приложения и его встроенные обновления поступают из оригинального проекта `2dust/v2rayN`. Этот репозиторий содержит русскоязычное описание и не подменяет официальные релизы.

Кнопка скачивания всегда ведёт на страницу **последнего стабильного релиза разработчика**. Новые версии не нужно вручную переносить в этот форк; они становятся доступны по той же ссылке после публикации разработчиком.

Исходный код форка проверяется на обновления из `2dust/v2rayN` раз в сутки и может быть синхронизирован вручную через Actions → **Sync upstream source**. Наши русские документы и настройки workflows сохраняются. При конфликте в остальных файлах автоматическое слияние останавливается без отправки изменений; результат виден в журнале Actions. Обновление исходников и появление релизов — независимые процессы.

Обновление **ядер** выполняется отдельно от обновления приложения. Перед заменой сохраните рабочую версию ядра и резервную копию настроек: автоматический откат ядра не подтверждён. Подробности — в [разделе об обновлениях](docs/ru/guide.md#обновление-приложения-и-ядер).
