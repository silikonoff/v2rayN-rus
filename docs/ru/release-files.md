# Какой файл v2rayN скачать

[← На главную](../../README.md) · [Официальный последний релиз](https://github.com/2dust/v2rayN/releases/latest)

Это русская адаптация [описания файлов релиза в wiki разработчика](https://github.com/2dust/v2rayN/wiki/Release-files-introduction), проверенная 9 ноября 2026 года. Состав и названия файлов могут измениться: перед скачиванием сверяйте их с конкретным официальным релизом.

## Перед установкой

Архивы ZIP предназначены для переносного запуска: их распаковывают в отдельный каталог. По описанию разработчика данные обычно сохраняются рядом с приложением; расположение может зависеть от варианта запуска и настроек. Несколько отдельных каталогов позволяют держать независимые копии.

В некоторые пакеты включены ядра **Xray, sing-box и mihomo**. Состав зависит от выпуска; другие ядра могут потребовать отдельной установки. Конфигурация сервера или подписка в комплект поставки не входит.

## Windows

В оригинальной wiki указана Windows 10 или новее. Выберите архитектуру системы и вариант интерфейса:

| Файл | Архитектура | Интерфейс |
|---|---|---|
| `v2rayN-windows-64.zip` | x64 | WPF |
| `v2rayN-windows-64-desktop.zip` | x64 | Avalonia |
| `v2rayN-windows-86.zip` | x86 | WPF |
| `v2rayN-windows-86-desktop.zip` | x86 | Avalonia |
| `v2rayN-windows-arm64.zip` | ARM64 | WPF |
| `v2rayN-windows-arm64-desktop.zip` | ARM64 | Avalonia |

Windows x86 указан по составу официального релиза 7.25.6: в рассмотренной версии wiki он отдельно не перечислен. Windows ARM64 доступен у разработчика, хотя в таблице на главной странице этого форка он не выделен.

## Linux

В wiki перечислены Debian 12+, Ubuntu 22.04+, Fedora 36+ и Red Hat 9+. Пакеты `.deb` предназначены для Debian/Ubuntu, `.rpm` — для совместимых систем семейства Fedora/Red Hat. Установленные системные пакеты используют пользовательские каталоги ОС; ZIP запускается из распакованной папки.

| Архитектура | ZIP | Debian / Ubuntu | Fedora / Red Hat |
|---|---|---|---|
| x64 | `v2rayN-linux-64.zip` | `v2rayN-linux-64.deb` | `v2rayN-linux-rhel-64.rpm` |
| ARM64 | `v2rayN-linux-arm64.zip` | `v2rayN-linux-arm64.deb` | `v2rayN-linux-rhel-arm64.rpm` |

Для ZIP разработчик предлагает после распаковки разрешить запуск файла `v2rayN` командой `chmod +x v2rayN`, затем запустить `./v2rayN` обычным пользователем. Для локальных пакетов используются соответственно `sudo apt install ./ИМЯ_ФАЙЛА.deb` или `sudo dnf install ./ИМЯ_ФАЙЛА.rpm`; подставьте фактически скачанное имя. В wiki x64 RPM назван с суффиксом `x64`, а в официальном релизе 7.25.6 — с суффиксом `64`.

## macOS

В wiki указана macOS 13.6 или новее.

| Компьютер | ZIP | Образ DMG |
|---|---|---|
| Intel x64 | `v2rayN-macos-64.zip` | `v2rayN-macos-64.dmg` |
| Apple Silicon ARM64 | `v2rayN-macos-arm64.zip` | `v2rayN-macos-arm64.dmg` |

Для ZIP в wiki указаны `chmod +x v2rayN` и запуск `./v2rayN` из распакованного каталога. Разработчик предупреждает, что DMG может содержать неподписанное приложение и macOS может его заблокировать. Прежде чем менять настройки защиты или атрибуты приложения, проверьте источник и актуальные инструкции разработчика; подпись и нотариальное заверение в рамках этой работы не проверялись.

## Проверка источника

Скачивайте файлы с [GitHub разработчика](https://github.com/2dust/v2rayN/releases/latest). У релизов могут быть отдельные файлы подписи `.sig`; их наличие само по себе не подтверждает подлинность без проверки доверенным ключом. Не публикуйте свои конфигурации и ссылки подписок при обращении за помощью.
