## Сборки и совместимость

Никакая сборка или запуск приложения на компьютере владельца не выполнялись по его указанию. Windows x64, Windows x86, Linux x64, macOS x64 и macOS ARM64: **workflow изменён/изучен статически, реальная сборка и запуск не проверены**. Полная проверка YAML, сборочных зависимостей, упаковки, GPG, macOS Gatekeeper, подписи Apple и нотариального заверения ещё необходима на предназначенных для этого runners. Публиковать непроверенные пакеты нельзя.

Linux x86 исключён по решению владельца. Удалённые скрипты использовали сторонние пакеты `linux-x86` и изменяли сведения SDK о поддерживаемых runtime. [Документация Microsoft по Debian](https://learn.microsoft.com/en-us/dotnet/core/install/linux-debian?tabs=dotnet10) указывает x64 и Arm64 для пакетов Microsoft; это не доказательство принципиальной невозможности сборки сторонними средствами.

Версия `7.25.6` и `net10.0` указаны в `v2rayN/Directory.Build.props`; WPF дополнительно использует Windows target. Код содержит русский `ResUI.ru.resx`, Xray и sing-box, подписки, выбор системного прокси и TUN. Поддержка отдельных сочетаний протокола, транспорта, ядра и платформы не проверена end-to-end. Автоматическая проверка обновлений в коде предусмотрена для v2rayN, Xray, mihomo и sing-box; встроенный источник самого v2rayN указывает на оригинал, поэтому замена форка оригинальной версией возможна. Автоматический безопасный откат ядра не подтверждён.

Локально выполнены проверка UTF-8, существования локальных ссылок и якорей для трёх русских Markdown-файлов, ограниченный поиск типовых шаблонов секретов в них, `git diff --check` и проверка DevOps workspace; ошибок не обнаружено. Статически проверены ссылки между workflows, целевая матрица и отсутствие Linux x86 в workflows. Анализатор YAML/GitHub Actions в доступной среде не найден. Сам workflow документации на GitHub не запускался. Тесты приложения и реальные сборки не выполнялись; исходники сетевой логики, данные пользователя, ресурсы интерфейса и версии ядер не изменялись.

## Оставшаяся работа перед релизом

- Фактическая проверка сборок и приложения на целевых ОС не входит в текущую задачу по решению владельца. Реальные снимки экранов не создавались: для будущей проверки нужны главный экран, импорт, подписки, настройки прокси, TUN, маршрутизация и обновление ядер.
- Проверка документации покрывает UTF-8, локальные файлы и якоря заголовков, но не является полноценным Markdown-линтером. Пять уникальных внешних ссылок в этих русских документах 9 ноября 2026 ответили HTTP 200 на HEAD; это не доказывает существования релизных артефактов.
- Привести имена опубликованных архивов к схеме с версией. Текущие имена сохраняются: встроенный updater ожидает конкретные имена оригинала, и их одностороннее изменение может нарушить совместимость. Согласовать дизайн обновления форка отдельно.
- Аудировать происхождение и целостность загружаемых при упаковке сетевых ядер: существующий ZIP workflow использует изменяемую ветку `2dust/v2rayN-core-bin` без закрепления checksum. Не считать такую цепочку проверенной.
- Проверить сокращённую CI-матрицу на GitHub при следующем разрешённом запуске; код WebAPI и связанные сценарии приложения не удалялись. Внешний аудит лицензий каждого стороннего компонента не проводился.
